# Unstructured Notes & Narrative: RHABDOMYOSARCOMA_PLEOMORPHIC

### metastasis_patterns_note
Adult; aggressive; lung-dominant metastasis; other common metastatic sites include bone and bone marrow.

### tumor_microenvironment.notes
Adult entity — distinct from paediatric RMS (alveolar, embryonal). Aggressive with poor prognosis. Behaves as high-grade pleomorphic sarcoma; response to paediatric RMS regimens (VAC) is inferior.

### cellular_states_and_lineage.notes
Adult entity distinct from paediatric ARMS/ERMS despite same lineage. Complex karyotype rather than defining fusion (unlike ARMS). Behaves as high-grade pleomorphic sarcoma; response to paediatric RMS regimens (VAC) is inferior; some centres treat as UPS. Aggressive with poor prognosis.
