# Unstructured Notes & Narrative: MUCINOUS_BREAST

### metastasis_patterns_note
Generally HR+ with favorable prognosis and lower nodal/distant metastatic rates than conventional invasive ductal carcinoma; when metastatic, bone is a common site, with lung and liver also reported.

### tumor_microenvironment.notes
Excellent prognosis for pure mucinous; type B may show neuroendocrine differentiation.

### cellular_states_and_lineage.notes
Favorable prognosis reflects well-differentiated luminal biology. Type A and type B patterns have been described, with type B showing greater cellularity and more frequent neuroendocrine differentiation. Somatostatin receptor expression can occur in neuroendocrine-differentiated cases, but this is not a defining hallmark of mucinous breast carcinoma.
