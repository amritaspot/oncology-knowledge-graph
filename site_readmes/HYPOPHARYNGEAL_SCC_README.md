# Unstructured Notes & Narrative: HYPOPHARYNGEAL_SCC

### metastasis_patterns_note
See ORAL_CAVITY_SCC — aggregated UAT data from Riihimäki 2018 applies. Hypopharyngeal SCC commonly metastasizes to lung and also to bone and liver in recurrent/metastatic disease; site-specific population-level quantification is limited here.

### tumor_microenvironment.notes
Smoking/alcohol-driven; UV-independent. Typically present at advanced stage which affects TME characterisation.

### cellular_states_and_lineage.notes
Same field-cancerization biology as other UAT SCCs. Late presentation because of clinically silent submucosal extension. Plummer-Vinson syndrome (iron deficiency + esophageal webs) is classic predisposing lesion, though rare now.
