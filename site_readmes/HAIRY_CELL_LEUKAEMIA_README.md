# Unstructured Notes & Narrative: HAIRY_CELL_LEUKAEMIA

### heme_involvement_pattern.notes
BRAF V600E mutation in classic HCL in the great majority of cases (near-universal). Highly responsive to cladribine or pentostatin; long-lasting remissions.

### tumor_microenvironment.notes
Highly responsive to cladribine or pentostatin (purine analogues) with long remissions. Vemurafenib active in R/R classic HCL. HCL variant / splenic B-cell lymphoma/leukaemia with prominent nucleoli is biologically distinct — BRAF wild-type, often MAP2K1-mutant, worse prognosis, no expected benefit from BRAF inhibitors.

### cellular_states_and_lineage.notes
BRAF V600E is a defining lineage-relevant event in classic HCL. Vemurafenib is active in relapsed/refractory classic HCL. Distinctive monocytopenia contributes to opportunistic infection risk. HCL variant / splenic B-cell lymphoma/leukaemia with prominent nucleoli is BRAF wild-type, often MAP2K1-mutant, with worse prognosis and no benefit from BRAF inhibitors.
