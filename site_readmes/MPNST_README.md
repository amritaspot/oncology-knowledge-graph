# Unstructured Notes & Narrative: MPNST

### metastasis_patterns_note
Lung-dominant metastasis; NF1-associated MPNSTs may present at younger age.

### tumor_microenvironment.notes
~40-50% arise in NF1 setting (lifetime MPNST risk ~8-13%). H3K27me3 loss is a useful diagnostic marker. Aggressive with poor response to chemotherapy. Selumetinib (MEK inhibitor) approved for NF1 plexiform neurofibromas but not for MPNST.

### cellular_states_and_lineage.notes
Same neural crest / Schwann cell lineage as schwannoma but with malignant biology. NF1 germline predisposes to plexiform neurofibroma  MPNST progression. Loss of H3K27me3 (from PRC2 disruption via EED/SUZ12) is diagnostic marker for MPNST distinguishing from benign schwannian tumours. Also can arise from radiation exposure. Selumetinib approved for NF1-related plexiform neurofibroma but not MPNST.
