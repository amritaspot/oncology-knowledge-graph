# Unstructured Notes & Narrative: PHEOCHROMOCYTOMA

### metastasis_patterns_note
Most pheochromocytomas are non-metastatic; metastatic disease occurs in a minority (overall ~10-15%, variable by genotype and cohort). Metastasis is defined by tumor in sites where normal chromaffin tissue is absent; common sites include bone, lymph nodes, liver, and lung. SDHB-mutant tumors have the highest metastatic risk.

### tumor_microenvironment.notes
Molecular subclassification includes pseudohypoxia cluster (SDHx, VHL, EPAS1/HIF2A, FH), kinase signalling cluster (RET, NF1, TMEM127, MAX, HRAS), and Wnt-altered subgroup (for example MAML3 fusion/CSDE1 alterations). Pseudohypoxia cluster has higher metastatic risk. Preoperative b1-blockade essential before surgery.

### cellular_states_and_lineage.notes
Neural crest origin explains catecholamine biology and parallels other neural crest tumours (paraganglioma, MTC, neuroblastoma). Chromaffin lineage-defining. Same pseudohypoxia biology (for example SDHx and FH alterations creating pseudohypoxic state) links pheochromocytoma/paraganglioma to some GISTs and renal cell carcinoma subsets. Cluster 1 (pseudohypoxia) has higher metastatic risk.
