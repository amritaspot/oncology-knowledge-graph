# Unstructured Notes & Narrative: OCULAR_ADNEXAL_LYMPHOMA

### metastasis_patterns_note
Most are extranodal marginal zone lymphomas of MALT type and are typically indolent and localized at presentation; systemic lymphoma staging/workup is required. This is a lymphoma, so spread patterns follow lymphomatous dissemination rather than a solid-tumour metastasis paradigm.

### tumor_microenvironment.notes
Doxycycline has shown activity in some early-stage ocular adnexal MALT lymphomas, particularly where Chlamydia psittaci is implicated, but this is not uniformly established across regions. Involved-site radiation therapy is a standard option for localized disease; rituximab-based therapy is used in selected cases. Indolent behaviour is usual.

### cellular_states_and_lineage.notes
Cross-reference to EXTRANODAL_MARGINAL_ZONE_MALT for shared lineage biology. Chlamydia psittaci association is geographically variable, so doxycycline is not a universal first-line standard despite use in some early-stage cases. Recurrent genetic alterations described in extranodal marginal zone lymphoma include TNFAIP3 loss/inactivation and, in subsets, MALT1/BCL10-associated translocations such as t(11;18)(q21;q21)/BIRC3::MALT1, t(14;18)(q32;q21)/IGH::MALT1, and t(1;14)(p22;q32)/BCL10::IGH, although frequencies in ocular adnexal cases are lower and site-variable. Indolent behaviour is typical.
