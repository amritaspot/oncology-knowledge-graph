# Unstructured Notes & Narrative: FOLLICULAR_THYROID

### metastasis_patterns_note
See PAPILLARY_THYROID for aggregate thyroid data. FTC has more haematogenous spread than PTC: bone and lung more prominent, cervical nodes less so.

### tumor_microenvironment.notes
Distant haematogenous spread more common than nodal. Less Hashimoto association than PTC. TME under-studied.

### cellular_states_and_lineage.notes
PAX8-PPARG fusion is a distinctive lineage-defining event affecting follicular transcriptional programme. Haematogenous spread pattern reflects retained follicular differentiation with iodine avidity (allowing RAI treatment of distant metastases).
