# Unstructured Notes & Narrative: PTCL_NOS

### heme_involvement_pattern.notes
Wastebasket category for PTCLs not fitting specific entities. Aggressive; poor prognosis with CHOP-based therapy; brentuximab vedotin + CHP is established for CD30-positive PTCL based on ECHELON-2, although the clearest evidence is in systemic ALCL and benefit in PTCL-NOS is less certain.

### tumor_microenvironment.notes
Wastebasket category for PTCLs not fitting specific entities. Aggressive with poor prognosis. Brentuximab vedotin + CHP improved outcomes versus CHOP in ECHELON-2 for CD30-positive PTCL overall, with strongest evidence in systemic ALCL; benefit in PTCL-NOS is less certain. GATA3-high signature associates with worse prognosis.
