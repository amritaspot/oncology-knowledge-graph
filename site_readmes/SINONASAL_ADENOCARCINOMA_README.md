# Unstructured Notes & Narrative: SINONASAL_ADENOCARCINOMA

### metastasis_patterns_note
Predominantly locoregional with local recurrence and cervical nodal spread in a minority of cases; distant metastasis is uncommon.

### tumor_microenvironment.notes
ITAC has strong occupational association (wood dust exposure  sawmill workers). Non-ITAC is heterogeneous.

### cellular_states_and_lineage.notes
ITAC is molecularly and morphologically distinct from other sinonasal tumours  behaves like colonic adenocarcinoma. Non-ITAC is a heterogeneous residual category.
