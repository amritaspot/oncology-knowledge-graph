# Unstructured Notes & Narrative: SALIVARY_POLYMORPHOUS

### metastasis_patterns_note
Low-grade malignant salivary gland tumour, usually indolent and locally infiltrative. Regional lymph node metastasis is uncommon but can occur, reported more often in the cribriform adenocarcinoma/cribriform variant spectrum; distant metastasis is rare.

### tumor_microenvironment.notes
Predominantly involves minor salivary glands (especially palate). Usually indolent behaviour. TME poorly studied.

### cellular_states_and_lineage.notes
Minor salivary gland (palate) predominance is characteristic. Indolent behaviour helps distinguish it clinically from adenoid cystic carcinoma, although both are infiltrative salivary malignancies. PRKD1 mutations activate the protein kinase D pathway.
