# Unstructured Notes & Narrative: NSCLC_ADENOSQUAMOUS

### metastasis_patterns.context
Frequencies among stage IV adenosquamous carcinoma patients WITH distant metastasis (n=858). Denominator = metastatic-disease subset only, not all ASC patients. Note this is a different denominator from the Wang 2020 lung data above.

### metastasis_patterns.organ_involvement.MUSCULOSKELETAL.notes
Bone; most frequent site among metastatic ASC.

### metastasis_patterns.organ_involvement.PULMONARY.notes
Contralateral / other lung.

### metastasis_patterns.organ_involvement.HEPATOBILIARY.notes
Liver.

### metastasis_patterns.organ_involvement.NEUROLOGIC.notes
Brain.

### tumor_microenvironment.notes
Aggressive with poor prognosis. Molecular testing should sample both components — driver alterations can be shared across both components, although intratumoral heterogeneity may occur.

### cellular_states_and_lineage.notes
Rare NSCLC variant. Distinct components often share key driver alterations, supporting common clonal origin, but heterogeneity can occur; comprehensive molecular testing remains important. Behaves as aggressive NSCLC. Recent literature suggests some cases represent squamous transformation from EGFR-mutant adenocarcinoma.
